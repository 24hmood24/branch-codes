# طلب كود الفروع

صفحة بسيطة يختار فيها الشخص **الفرع**، ويضغط **«اطلب الكود»**، فيطلع له **كود الفرع**. بعدها تطلع له **أسئلة فورم قوقل** يعبيها ويرسلها.

| الشي | من وين يجي / وين يروح |
|---|---|
| الفروع والأكواد | الشيت، ورقة **«الأكواد»** |
| الأسئلة | **فورم قوقل** حقك. أي تعديل في الفورم يطلع في الصفحة خلال دقيقة |
| الإجابات | الشيت، ورقة **«الردود»**، ومعها الوقت والفرع والكود |

- **كود واحد ثابت لكل فرع.** كل اللي يختارون نفس الفرع ياخذون نفس الكود، لين أنت تغيّره في الشيت.
- **الأكواد ما تنكشف.** الصفحة فيها أسماء الفروع بس، والكود ما يطلع إلا بعد الطلب، وبس كود الفرع المختار.
- **تشتغل للكل**، حتى اللي مسجّل بأكثر من حساب قوقل. السبب إن الصفحة مستضافة برّا قوقل وتكلّم السكربت بدون كوكيز.

```
الزائر ──► الصفحة (GitHub Pages) ──► Apps Script (API) ──► الشيت + الفورم
```

---

## ⚡ الطريقة السريعة (بدون GitHub، من أي جهاز: ويندوز أو ماك أو جوال)

كل الخطوات في المتصفح، ما فيه شي تحمّله على جهازك.

1. **انسخ القالب:** افتح هذا الرابط واضغط **Make a copy**. تنسخ عندك نسخة من الشيت ومعها السكربت.
   👉 https://docs.google.com/spreadsheets/d/1x4Wa1OFCVeVYUKSTOR6bs2kCjTkk1-amxzNU6utyshA/copy
2. **في النسخة:** انتظر ثواني لين يطلع فوق قائمة **⚙️ تجهيز**، واختر **١) تجهيز وربط الفورم**.
   - أول مرة بيطلب موافقة: **Continue** ← اختر حسابك ← **Advanced** ← **Go to … (unsafe)** ← **Allow**، وبعدها اختر **١)** مرة ثانية.
   - الصق رابط **التعديل** حق فورم قوقل حقك (اللي ينتهي بـ `/edit`)، أو خلّه فاضي عشان نسوي لك فورم تجريبي.
3. **⚙️ تجهيز ← ٢) طريقة النشر** واتبع الخطوات. هي ٤ ضغطات: Deploy ← New deployment ← Web app ← Anyone ← Deploy.
4. **⚙️ تجهيز ← ٣) رابط الصفحة للناس**، وانسخ الرابط. هذا رابطك اللي ترسله للناس ✅

بعدها كل شي من الشيت: الفروع والأكواد في **«الأكواد»**، والإجابات تنزل في **«الردود»**، والأسئلة تعدّلها من الفورم.

> 💡 إذا المتصفح فيه أكثر من حساب قوقل وطلعت لك «الصفحة غير موجودة» وأنت تجهّز، سوّ التجهيز من نافذة خاصة (Incognito). الناس اللي يفتحون رابطك ما يتأثرون بهذا.

> ℹ️ صفحتك تستخدم الصفحة العامة `24hmood24.github.io/branch-codes`، وبياناتك كلها في الشيت حقك أنت. إذا تبي تستضيف الصفحة بنفسك، اتبع «التركيب من الصفر» تحت.

## محتويات المشروع

```
index.html            الصفحة (قائمة فروع مع بحث + الكود + أسئلة الفورم)
config.js             الإعدادات: رابط الـ API والعنوان (الملف الوحيد اللي تعدّله في الصفحة)
apps-script/Code.gs   الكود اللي ينحط في Google Apps Script
```

## التركيب من الصفر

### 1) سوّ الشيت

1. افتح [sheets.new](https://sheets.new) وسمّه مثلاً «أكواد الفروع».
2. ما يحتاج تكتب شي، خطوة 3 تسوي الأوراق لحالها.

### 2) حط الكود في Apps Script

1. من داخل الشيت: **Extensions ← Apps Script**.
2. امسح الموجود في `Code.gs`، والصق محتوى ملف [`apps-script/Code.gs`](apps-script/Code.gs) كامل.
3. فوق في أول الملف عدّل الإعدادات:
   ```js
   const SHEET_ID = '';   // خلّه فاضي لأن السكربت داخل الشيت
   const FORM_URL = '';   // رابط فورم قوقل حقك (شوف القسم تحت)
   ```
4. احفظ (⌘S أو Ctrl+S).

> 💡 **إذا ظهرت لك «الصفحة غير موجودة» لما تفتح Apps Script:** معناها المتصفح مسجّل فيه أكثر من حساب قوقل. افتح نافذة خاصة (Incognito) وسجّل بحساب واحد. أو روح [script.google.com](https://script.google.com) وسوّ **مشروع جديد**، وحط في `SHEET_ID` رقم الشيت. رقم الشيت هو الجزء اللي بين `/d/` و`/edit` في رابطه.

### 3) شغّل التجهيز مرة وحدة

1. من القائمة فوق اختر الدالة **`setup`** واضغط **Run**.
2. قوقل بيطلب موافقة: **Review permissions** ← اختر حسابك ← **Advanced** ← **Go to … (unsafe)** ← **Allow**.
   التحذير عادي لأن السكربت حقك أنت.
3. بعدها بيكون في الشيت ورقتين:
   - **الأكواد**: فيها ٣ فروع تجربة (امسحها بعدين).
   - **الردود**: فاضية، ويتعبّى فيها كل إرسال.
4. إذا خليت `FORM_URL` فاضي، `setup` تسوي **فورم تجريبي** وتطبع رابطه في **Execution log**.

### 4) انشر الـ API

1. **Deploy ← New deployment**.
2. اضغط ⚙️ بجنب «Select type» واختر **Web app**.
3. **Execute as:** `Me`. **Who has access:** `Anyone`.
4. **Deploy**، وانسخ الرابط اللي ينتهي بـ `/exec`.

### 5) حط الرابط في الصفحة

افتح `config.js` وحط الرابط:

```js
API_URL: 'https://script.google.com/macros/s/XXXXXXXX/exec',
```

### 6) ارفع الصفحة على GitHub Pages

1. ارفع الملفات لمستودع (repo) **Public** على GitHub.
2. في المستودع: **Settings ← Pages**.
3. **Source:** `Deploy from a branch`. **Branch:** `main` / `(root)`، واضغط **Save**.
4. بعد دقيقة أو دقيقتين يطلع لك الرابط: `https://<اسمك>.github.io/<اسم-المستودع>/`

هذا الرابط اللي ترسله للناس.

## الاستخدام اليومي

### إضافة فرع أو تغيير كود

في ورقة **«الأكواد»**:

| A الفرع | B الكود |
|---|---|
| فرع القطيف | QTF-2026 |
| فرع الدمام | DMM-2026 |

- **فرع جديد:** صف جديد فيه الاسم والكود، ويطلع في الصفحة على طول.
- **تغيير كود:** عدّل الخلية في عمود B بس. من بعدها كل اللي يطلب يجيه الكود الجديد.
- **إيقاف فرع:** امسح الكود وخلّ الخلية فاضية، وبتطلع للي يطلب «ما فيه كود لهذا الفرع حالياً». أو امسح الصف كامل.
- **أول صف** (العناوين) لا تمسحه.

### ربط فورم قوقل حقك (الأسئلة)

1. افتح الفورم حقك، وانسخ رابط **التعديل** من شريط العنوان، اللي ينتهي بـ `/edit`. **مو** رابط المشاركة.
2. في Apps Script حطه في:
   ```js
   const FORM_URL = 'https://docs.google.com/forms/d/XXXXXXXX/edit';
   ```
3. احفظ، وشغّل **`setup`** مرة ثانية. لو طلب موافقة وافق.
4. **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy**. الرابط ما يتغيّر.

> ⚠️ **الحساب اللي عليه السكربت لازم يكون محرّر (Editor) في الفورم.** إذا الفورم على حساب ثاني، افتح الفورم من ذاك الحساب، واضغط ⋮ ← **Add collaborators**، وأضف إيميل حساب السكربت.

**أنواع الأسئلة اللي تشتغل:**

| في فورم قوقل | في الصفحة |
|---|---|
| إجابة قصيرة | خانة نص. إذا العنوان فيه «جوال» تصير خانة رقم جوال مع تحقق، وإذا فيه «بريد» تصير خانة إيميل |
| فقرة | خانة نص كبيرة |
| اختيار من متعدد / قائمة منسدلة | اختيار واحد |
| مربعات اختيار | أكثر من اختيار |
| مقياس خطي | اختيار رقم |
| تاريخ / وقت | تاريخ / وقت |
| عنوان قسم | عنوان بدون خانة |

- **السؤال المطلوب** في الفورم يصير مطلوب في الصفحة، ويطلع جنبه نجمة.
- **الأسئلة نفسها** من الفورم، لكن **الإجابات تروح لورقة «الردود»**، مو لردود الفورم.
- **سؤال جديد** في الفورم يضيف له عمود جديد في «الردود» من أول إرسال.

### الإجابات

ورقة **«الردود»**: كل إرسال في صف:

| الوقت | الفرع | الكود | الاسم الكامل | رقم الجوال | … |
|---|---|---|---|---|---|

## تعديل الكود بعدين

- **تعديل في `Code.gs`:** احفظ، وبعدها **Deploy ← Manage deployments ← ✏️ ← New version ← Deploy**. لا تسوي *New deployment* لأنه يغيّر الرابط.
- **تعديل في الصفحة** (`index.html` أو `config.js`): ارفعه على GitHub، وGitHub Pages يحدّثه خلال دقيقة.
- **العنوان والوصف:** ياخذهم من الفورم تلقائياً. إذا تبي غيرهم، اكتبهم في `TITLE` و`SUBTITLE` داخل `config.js`.

## تجربة الصفحة على جهازك

```bash
python3 -m http.server 8790
```

بعدها افتح `http://localhost:8790`.

## مشاكل شائعة

| المشكلة | الحل |
|---|---|
| «تعذّر الاتصال» | تأكد إن `API_URL` في `config.js` ينتهي بـ `/exec`، وإن النشر على **Anyone** |
| ما تطلع أسئلة | تأكد من `FORM_URL`، وإن حساب السكربت محرّر في الفورم، وشغّل `setup` |
| عدّلت الكود وما تغيّر شي | ما سويت **New version** في Manage deployments |
| تعديل الفورم ما طلع | انتظر دقيقة، لأن الأسئلة تتخزّن دقيقة |
| «ما فيه كود لهذا الفرع» | خانة الكود فاضية في ورقة «الأكواد» |
