# طلب كود الفروع

صفحة يختار فيها الموظف **الفرع**، ويضغط **«اطلب الكود»**، فيطلع له **كود الفرع**. بعدها يعبّي **أسئلة فورم قوقل** (مع الصورة) ويرسلها.

| الشي | من وين يجي / وين يروح |
|---|---|
| الفروع والأكواد | الشيت، ورقة **`codes`**: B الفرع، C الكود، D الحالة (`Not used` / `Used`) |
| الأسئلة | **فورم قوقل** نفسه. أي تعديل في الفورم يطلع في الصفحة خلال دقيقة |
| الإجابات | الشيت، ورقة **`Responses`**. كل جواب تحت العمود اللي بنفس اسم السؤال |
| الصور | تتصغّر وترتفع لمجلد **«صور طلب كود»** في Drive، ورابطها ينكتب في عمود السؤال |

- **الكود ينستخدم مرة وحدة.** بعد ما أحد يرسل، الحالة في D تصير **`Used`**، واللي يطلب نفس الفرع تطلع له «كود هذا الفرع انستخدم، اطلب من الإدارة كود جديد».
- **تكتب كود جديد في C**، والحالة ترجع **`Not used`** لحالها.
- **عمود الكود** (`CODE…`) ينكتب لحاله، وسؤاله ما ينسأل.
- **سؤال الفرع** (`BRANCH…`) يطلع **مختار تلقائياً** على أقرب اسم لفرع الكود، عشان ينكتب بنفس أسماء الفورم.
- **الأعمدة اللي مو أسئلة** (مثل `Checked?`) ما تنلمس.
- **الصفوف الجديدة** تاخذ نفس تنسيق الصف اللي فوقها (شكل الوقت، SAR…).
- **الصفحة تشتغل للكل**، حتى اللي مسجّل بأكثر من حساب قوقل، لأنها مستضافة برّا قوقل وتكلّم السكربت بدون كوكيز.

```
الموظف ──► الصفحة (GitHub Pages) ──► Apps Script ──► الشيت (codes + Responses) + الفورم + Drive
```

---

## محتويات المشروع

```
index.html            الصفحة (بحث الفروع + الكود + أسئلة الفورم + رفع الصور)
config.js             رابط الـ API الافتراضي والعنوان
apps-script/Code.gs   الكود اللي ينحط في Google Apps Script (داخل الشيت)
```

---

## التركيب على الشيت

> الحساب اللي يسوي الخطوات هذي لازم يكون **محرّر** في الشيت **و** في الفورم.

### 1) حط الكود
1. افتح الشيت، وروح **Extensions ← Apps Script**.
2. امسح الموجود، والصق محتوى [`apps-script/Code.gs`](apps-script/Code.gs) كامل. تقدر تنسخه من صفحة الملف بزر **Copy raw file**.
3. في أول الملف حط رابط **تعديل** الفورم (اللي ينتهي بـ `/edit`):
   ```js
   const FORM_URL = 'https://docs.google.com/forms/d/XXXX/edit';
   ```
4. احفظ (⌘S أو Ctrl+S).

> 💡 **إذا طلعت لك «الصفحة غير موجودة»:** المتصفح فيه أكثر من حساب قوقل. سوّ الخطوات من **نافذة خاصة (Incognito)** مسجّل فيها بحساب واحد.

### 2) الموافقة
اضغط **Run** فوق (أي دالة، مثل `doGet`)، وبعدها: **Review permissions** ← اختر الحساب ← **Advanced** ← **Go to … (unsafe)** ← **Allow**.

### 3) النشر
1. **Deploy ← New deployment**.
2. اضغط ⚙️ واختر **Web app**.
3. **Execute as:** `Me`. **Who has access:** `Anyone`.
4. اضغط **Deploy**.
   - إذا طلع **Authorise access** ووافقت، بس طلعت «يتعذّر فتح الملف»: اضغط **Cancel** وسوّ **New deployment** مرة ثانية، وبيمشي.
5. انسخ الرابط اللي ينتهي بـ `/exec`.

### 4) رابط الصفحة للموظفين

```
https://<صفحة GitHub>/?api=<رابط exec>
```

أو تحط رابط `exec` في `API_URL` داخل `config.js`، وتستخدم رابط الصفحة بدون `?api=`.

## الاستخدام اليومي

### الأكواد (ورقة codes)
| B Branch | C Code | D stats |
|---|---|---|
| Al Mubarraz - Ahsa | 55555 | Not used |

- **كود جديد لفرع:** اكتبه في C، والحالة ترجع `Not used` لحالها.
- **فرع جديد:** صف جديد تحت الجدول فيه الاسم والكود.
- **فرع بدون كود:** خلّ C فاضي، وبتطلع للي يطلبه «ما فيه كود لهذا الفرع حالياً».

### تعديل الفورم
- **تغيير كلام سؤال أو خياراته، أو إضافة سؤال:** من الفورم نفسه، والصفحة تتحدّث خلال دقيقة. ما يحتاج تلمس الصفحة ولا الكود.
- **أسماء أعمدة Responses** تتغيّر لحالها مع أسماء الأسئلة لأن الشيت مربوط بالفورم، فالإجابات تضل تنزل في أعمدتها.
- **سؤال الكود:** خلّ عنوانه يبدأ بـ `CODE` (أو يكون `الكود`) عشان ينعرف وينعبّى لحاله.
- **سؤال الفرع:** خلّ عنوانه يبدأ بـ `BRANCH` (أو يكون `الفرع`) عشان يطلع مختار تلقائياً.
- **إذا شلت سؤال الفرع:** عمود الفرع بينكتب فيه اسم الفرع من ورقة codes.

### تعديل الكود بعدين
بعد أي تعديل في `Code.gs`: احفظ، وبعدها **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy**. الرابط ما يتغيّر.
**لا** تسوي *New deployment*، لأنه يعطيك رابط جديد.

## تجربة الصفحة على جهازك

```bash
python3 -m http.server 8790
```

بعدها افتح `http://localhost:8790/?api=<رابط exec>`

## مشاكل شائعة

| المشكلة | الحل |
|---|---|
| «تعذّر الاتصال» | تأكد إن رابط `exec` صحيح وإن النشر على **Anyone** |
| «ليس لديك إذن…» | حساب السكربت مو **محرّر** في الفورم. أضفه من ⋮ ← Add collaborators |
| «كود هذا الفرع انستخدم» | اكتب كود جديد في C |
| عدّلت الكود وما تغيّر شي | ما سويت **New version** في Manage deployments |
| تعديل الفورم ما طلع | انتظر دقيقة |
